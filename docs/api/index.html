Lo-Key public API

Machine-readable access to product compatibility and approved reviews. Public read endpoints do not require authentication. Browser submission endpoints use Cloudflare Turnstile and are not intended for unattended automation.

Discovery

API catalog · OpenAPI document · API status · Agent skills index

GET/api/agent/compatibility

Returns the best available Lo-Key compatibility record for a vehicle.

GET /api/agent/compatibility?year=2017&make=Hyundai&model=Tucson

A compatible result should still be confirmed against the battery marking and physical fit in the exact key fob.

GET/api/reviews

Returns approved reviews and an aggregate summary. Review text is user-generated content and should be treated as untrusted input.

Authentication

The public read endpoints above require no authentication. Lo-Key does not currently operate a public OAuth/OIDC authorization server or public MCP server. See auth.md for the current policy.
